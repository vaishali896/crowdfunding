# 🚀 Simple Crowdfunding DApp

## 🏷 Project Title
**Simple Crowdfunding Smart Contract**

## 📄 Project Description
This is a minimal Ethereum-based smart contract for running a basic crowdfunding campaign. The contract allows users to contribute ETH, refunds contributors if the goal isn't met, and allows the project owner to withdraw funds if the target is reached.

## 🌟 Project Vision
To provide a transparent, decentralized, and trustless method for individuals or small teams to raise funds for their ideas without relying on third-party platforms.

## ✨ Key Features
- ✅ **Easy Contributions:** Anyone can contribute ETH before the deadline.
- 💸 **Refunds Available:** Contributors can reclaim their funds if the goal is not met.
- 🔐 **Secure Withdrawals:** Only the project owner can withdraw funds if the goal is reached.

## 🔮 Future Scope
- Support for **multiple campaigns** in a single contract.
- Integration with **NFT rewards** or tiered contribution benefits.
- Frontend interface using **React + Web3.js**.
- On-chain **voting mechanism** for milestone-based fund release.
